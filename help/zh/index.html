启动和相机选择

打开 start.sh 或 Tiny 启动器。发现后自动开始实时查看。顶部选择Tiny 2或Logitech C922；预览自动切换。 Tiny 2 被唤醒并在开始视频之前检查其状态。如果适用，将相机传递到虚拟机。录制期间相机选择被锁定。

实时视图和错误

连接实时视图保持可见，直到第一帧到达，然后实时视图运行。相机→停止实时取景停止；相机 → 开始实时取景重新启动。当预览停止并重新启动所选摄像机时，F5 会重新发现设备。检查 USB、其他相机应用程序和登录错误。

控制

侧栏中提供了移动和缩放、跟踪、图像和对焦、预设和相机设置。它们提供微型控制、主题跟踪、图像控制和保存的相机位置；可用的 UVC 控制取决于相机驱动程序。诊断仍然隐藏。还提供图像格式、视频、音频、相机配置文件和虚拟相机输出。视频包含相机分辨率、帧速率和像素格式，以及录制格式、质量、比特率、旋转、滤镜和录制持续时间。

镜像

相机 → 水平镜像适用于实时取景、PNG 和视频。该选择已保存，并且也会显示在“设置”中。像素瞄准使用当前未修改的预览并补偿镜像。录制期间镜像更改被锁定。

录音和摄像麦克风

捕获 → 保存快照写入 PNG (Ctrl+S)。捕获→录制视频写入WebM（Ctrl+R）；完成录制将其关闭（Ctrl+Shift+R）。启用音频后，录音始终使用属于所选摄像机的麦克风，并通过其物理 USB 父级进行匹配。没有单独的麦克风选择器。相机输入丢失或静音会产生错误；没有其他麦克风被替代。可以明确禁用录制音频。现有文件受到保护。关闭首先完成活动录制。相机媒体未上传。

图片格式

选择相机报告的格式。选择可用格式：PNG、JPEG、BMP、ICO/CUR、TIFF 或 WebP，然后单击“保存图像”。音频页面还提供单独的麦克风录音及其自己的目标文件夹和本地可用的音频格式。视频录制还可以包括音频：Opus (WebM/MKV)、AAC (MP4) 或 PCM (AVI)，具体取决于安装的编码器。

格式和限制

测试：C922，1080p/30 和 720p/30 或 60；小小 2，720p/30。文件 → 设置设置下一次预览开始的宽度和帧速率。 C922 没有电动万向节或 OBSBOT 跟踪。 Linux 上的微小 2 位置读取可能会报告最后一个目标；速度移动和滚动不可用。跟踪可以覆盖手动移动。

语言和语音命令

文件→设置提供十种界面语言和本地语言包导入。语言更改会立即更新界面和响应。该应用程序还没有语音识别器。根据制造商的说法，相机内置的 Tiny 2 语音控制支持英语和普通话，没有德语设置。德国软件语音命令需要单独的扩展。

帮助和诊断

F1 和帮助 → 帮助打开此本地指南。帮助→关于显示依赖项和贡献者；帮助 → 日志打开有限的本地日志。单独的诊断页面已从此界面中删除。

视频格式和相机控制

使用视频格式页面选择摄像机报告的分辨率、帧速率和像素格式。更改格式会重新启动预览。显示将协商的帧速率和测量的帧速率分开。此界面中不提供单独的相机控制页面。

捕捉

使用图像格式保存照片。视频页面开始和停止录制并询问保存位置。视频包含相机分辨率、帧速率和像素格式，以及容器、质量、比特率、旋转、录制持续时间和过滤器。音频使用选定的 USB 摄像头麦克风。十字准线和水印仍仅显示。

相机配置文件

输入配置文件名称并单击“保存”。要恢复配置文件，请选择它并单击“加载”。配置文件包括视频格式和帧速率、记录格式和选项、旋转、灰度、负片、镜像、十字准线和有效的相机图像控制。它们存储在每个摄像机本地的camera_profiles.json 中。不存储微小的平移/倾斜和虚拟摄像机输出。要删除配置文件，请选择它并单击删除。

附加 → 恢复驱动程序默认值在确认后重置有效控件。无效的驱动程序值和单独的 Tiny 移动控件被排除在外。这不是制造商恢复出厂设置。

闭幕式

关闭完成录音并使该应用程序使用的微型相机进入睡眠状态，即使在切换到罗技之后也是如此。报告无法确认睡眠。

其他相机和错误

其他V4L2相机通过其捕获能力进行检测。支持取决于设备、Linux 驱动程序和编解码器。 F5 在预览停止时刷新设备列表。 VM 需要显式 USB 直通。诊断页面已被删除；日志仍然可以从“帮助”→“日志”中获取。

虚拟相机

在虚拟摄像机下选择已配置的输出设备和视频格式。使用“附加”→“虚拟摄像头”来开始或停止转发。包括图像滤镜；显示覆盖被排除在外。只能转发物理源，以防止反馈循环。需要单独配置的 akvcam 或 v4l2loopback 驱动程序。配置示例可以保存而不应用。仅转发视频；在接收应用程序中使用物理相机的麦克风。

语音/手势

侧边栏页面包含“语音”和“手势”选项卡。每个命令和手势都有自己的可见行和独立保存的开关。语音还包含识别语言（英语/中文）。选择一行，设置其值并单击“应用”。仅发送活动选项卡中突出显示的行。更改开关会自动突出显示其行。请检查相机上的效果。

手势：张开手掌进行追踪；拇指和食指形成“L”形状以进行变焦；两只L形手进行动态变焦，然后改变它们的距离。反转变焦方向使用相同的双手手势。将双手放在脸旁边。

捕获质量和故障处理

JPEG 图像质量单独保存，适用于单张照片和系列。其他图像格式禁用此控件。照片系列使用选定的图像格式。 MP4/H.264 质量由比特率控制。如果没有视频编码器，则无法录制和保存配置文件。失败的音频终结会保留文件并报告其位置。不可靠的驱动控制是只读的；使用图像和焦点进行 Tiny 2 曝光。
